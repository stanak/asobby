# プライバシーポリシーと問い合わせ対応

## 公開文書

- 日本語: `/privacy` → `app/static/privacy.html`
- 英語: `/privacy?lang=en` → `app/static/privacy-en.html`
- 共通スタイル: `app/static/privacy.css`
- ログイン、OAuth、DB、JavaScript、アクセス解析、presence計測に依存しない。
- ナビゲーション、ログイン前の案内、意見・報告ページ、Windows/Wineクライアントのメニューから辿れる。
- 言語版は両方同時に更新する。文書更新日は静的な日付で、アクセスごとに変えない。

この文面はasobby.comの運用についてのもの。他の運営者がセルフホストする場合は、
連絡先、取得項目、保存先、連携先等をその運用に合わせて置き換える。

## 今回の方針

- 専用の退会・一括削除機能は設けない。利用終了に手続きは不要。
- 利用終了・ログアウト・クライアント削除では、サーバー上のデータを自動削除しない。
- ゲーム内名を含む戦績・リプレイは、履歴・統計・閲覧機能のため継続保存する。
- 「一切削除しない」「全データを匿名化する」「停止後は他の経路からも取得しない」とは説明しない。
- dpaletteは同じ運営者のサービス。ただしDiscordへの送信と、掲載先利用者への公開は別途説明する。
- 開示・訂正・削除・利用停止等の窓口: `midoristar@empengineer.cool` / Discord `midorist` (`204966469593858048`)。

## 申し出を受けたとき

1. 対象（アカウント、プロフィール、特定の試合・リプレイ、チャット等）と希望する対応を確認する。
   公開チャンネルへの投稿やasobbyへの再ログインを必須にしない。必要最小限の本人確認を行い、
   パスワード・セッショントークン・APIキーを求めない。
2. 取得元を区別する。Discord API由来のID・名前・アバターと、ゲーム由来の名前・リプレイは同一ではない。
   Discord開発者規約第5節では、本人の依頼、機能上不要になった場合等のAPIデータ削除が求められる。
   ゲーム由来の情報についても適用法令等を確認し、削除等の必要な申し出を一律に拒否しない。
3. 対象を読み取りで特定し、PostgreSQL、募集・チャット保存先、ログ、dpalette、管理下のDiscord投稿、
   バックアップ等への影響と処理範囲を確認する。全ユーザー検索や公開APIに対象の情報が残らないか確認する。
4. 必要な変更・削除は個別に内容を確認して実施する。アカウント削除は外部キーや共有試合に影響するため、
   `users` 行だけを無計画にDELETEしない。現行スキーマでは `Replay.match_id` がCASCADEで試合に連動する。
   名前は試合行、リプレイ検索、ファイル名にも残り、バイナリは未加工で保存される。
   Discord情報との紐付けを外すだけで匿名化できたと扱わない。
5. セッション・キャッシュ・外部連携からの再公開や、再同期による復元も検証する。
   対応した範囲、未処理の範囲と理由、外部サービスへの対応状況を依頼者に説明する。
   本人確認に使った情報・対応記録も必要最小限で管理する。

この文書は自動的な削除処理を追加するものではない。問い合わせを放置しないための実運用が必要。
削除条件が不明な場合は、法令・契約を確認し、必要に応じて専門家に相談する。

## 公開・運用で確認する事項

- Discord Developer PortalのPrivacy Policy URLを `https://asobby.com/privacy` に設定する。
  この値はリポジトリのデプロイでは変更されない。
- 運営者の法令上の氏名・名称・住所等について、照会に遅滞なく回答できるよう準備する。
  文面の窓口名 `midorist` だけで法令上必要な周知事項がすべて充足するとは断定しない。
- Fly.io・Neon等の実際の保存地域、アクセス権限、保存時の暗号化、バックアップ・ログの期間を確認する。
  ソースのFly設定は `nrt` だが、それだけで全データが日本国内に限定されるとは説明しない。
- 一律の日数による自動削除は未実装。利用目的上不要になった情報の見直し・削除を実施する。
  Discord APIデータの削除要件は、個別依頼がある場合だけに限定されない。
- チャットの「1時間・100件」は表示条件。保存先の物理削除・ログ・バックアップ・Discordの期間と混同しない。
- dpaletteの掲載先、Discordチャンネルの公開範囲、APIの `include_address` / `include_chat` 権限を確認する。
  同一運営者でない連携の追加時は、その提供条件・告知・必要な利用者の指示等を別途整理する。
- Google Analyticsの実際の設定、保持期間、広告機能、対象地域の同意要件を確認する。
  本変更は同意バナーを追加せず、既存ページの解析の挙動も変更しない。
  ポリシーのリンクを置くことだけで必要な同意取得を代替したとは扱わない。
- 公開時の本番動作と本文に差がないことを確認する。本文は法的適合性の保証ではない。
