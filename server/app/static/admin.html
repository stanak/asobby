募集作成を許可する連携は、投稿者の確認と IP 掲載への同意を取得してください。登録後はホストの生存確認で掲載を維持し、固定の掲載期限・手動終了操作はありません。この権限を外すか連携を停止・削除すると、その連携の募集も取り下げます。

IP を含めない場合も、表示名・投稿者の Discord ID・コメント・対戦状態などは連携先が取得できます。API キーの共有先と、一覧の掲載先を確認してください。
